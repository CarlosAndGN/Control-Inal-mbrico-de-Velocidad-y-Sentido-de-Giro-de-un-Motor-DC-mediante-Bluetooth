CONTROL INALÁMBRICO DE VELOCIDAD Y SENTIDO DE GIRO PARA UN MOTOR DC MEDIANTE BLUETOOTH

Autor: GURIDI NAVA CARLOS ANDRÉ

El presente proyecto fue realizado como parte de la evaluación de la materia de Microcontroladores para la carrera de Ingeniería en Telecomunicaciones, Sistemas y Electrónica de la UNAM.
Con el mismo se busca demostrar los conocimientos adquiridos durante el curso los cuales contemplan:

- Uso del software recomendado durante el curso (MPLABX y CCS).
- Uso de al menos uno de los microcontroladores estudiados durante el curso.
- Correcta lectura e interpretación de las hojas de datos de cada microcontrolador empleado durante el curso.
- Correcta elección del microcontrolador para el proyecto, partiendo de las características presentadas en la hoja de datos.
- Capacidad de diseñar e implementar circuitos empleando los elementos de software y hardware vistos durante el curso.
